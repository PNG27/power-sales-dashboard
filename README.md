# 📊 Market Maven – Power BI Sales Dashboard

This Power BI project showcases a detailed sales performance dashboard for **Market Maven**, providing actionable insights across product brands, revenue trends, transactions, and returns.

![Market Maven Dashboard](60c4810f-d3a4-464e-95fa-de9a183b737c.png)

---

## 🧠 Project Overview

The goal of this project is to analyze and visualize sales, profit, and transaction data across different dimensions like:
- Product brands
- Store countries
- Sales regions
- Monthly and yearly trends

This dashboard enables decision-makers to:
- Track **revenue vs. target**
- Monitor **profit growth**
- Analyze **returns distribution**
- Understand **monthly transactions**
- Compare **store performance by country**

---

## 🚀 Features

- ✅ **Product Brand Performance** – Visual comparison of total profit, cost, and transactions per brand
- 📍 **Geographical View** – Tree map of total transactions by country
- 📈 **Revenue vs. Target KPI** – Track progress toward revenue goals
- 📅 **Yearly Revenue Trends** – Analyze growth across years
- 💰 **Total Profit Insights** – KPI card with goal comparison
- 🍕 **Returns Analysis** – Donut chart of returns by sales region
- 📊 **Monthly Transactions** – Trend line of total transactions month-wise

---

## 🛠 Tools Used

- **Power BI Desktop**
- **Power Query** (for data transformation)
- **DAX** (for calculated metrics)

## 💡 Insights

- The **USA** leads in total transactions.
- Brands like **Hermanos** and **Tell Tale** generate the highest profit.
- The **total profit goal** is exceeded by over 147%.
- Revenue has shown a strong upward trend in the latest years.

## 📌 How to Use

1. Open the `.pbix` file using Power BI Desktop.
2. Explore each visual for deeper insights.
